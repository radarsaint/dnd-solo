# Board archive

Finished collaboration-board entries live here, one file per day (`YYYY-MM-DD.md`). The live list is [`../BOARD.md`](../BOARD.md). Read that by default. Open a file in this folder only when you need an old entry.

The four files `2026-09-30.md`, `2026-10-01.md`, `2026-10-02.md`, and `2026-10-03.md` are the board as it stood before the split, cut on date boundaries and otherwise unchanged. Concatenate them in that order to recover that text byte for byte (826 lines, SHA-256 `7a8cb92af8032e73f0a8ed8bdaa56577f95983c0b3354c2e91c5b495e3b71a96`). Do not edit those four files.

When an item on the live board is finished, append that entry verbatim to the file for its date, or create `YYYY-MM-DD.md` if the day does not have one yet. An archived ask is not current.
