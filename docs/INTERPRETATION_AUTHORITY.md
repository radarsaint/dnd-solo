# Interpretation authority repair

Independent review of v0.17.0 reproduced private-fact disclosure, remote actor
installation and ambiguous grouped-actor corrections. Quotation matching verifies
source bytes, not the proposed conclusion. These are authority boundaries rather
than a problem to solve with a growing list of English keywords.

Preparation can withhold initial source information but cannot disclose private
facts, reveal hidden actors or erase earned player knowledge. Discovery remains
an adjudicated event. Both opening and later-room paths retain unmatched people
as private PROPOSED candidates, excluded from installed actors, speakers, combat
and public views. Read-aloud bookkeeping cannot bypass the opening inventory.

This deliberately removes automatic admission of omitted people. A general
semantic admission mechanism is not implemented; do not describe private proposals
as restored native actors or claim that this makes every source interpretation
correct. Source-name/statistics corrections still require their bounded evidence
and an unambiguous established actor. Exact IDs take priority over names; ambiguous
group-wide individual corrections refuse.

Imported adventures now request interpretation by default in normal start/prepare
and the CLI, without an opt-in flag. Explicit world_response=False remains a Python
compatibility path for compiler/engine fixtures. Older source interpretations
require explicit reconciliation before reuse; corrupted knowledge is not silently
declared repaired. No automatic save migration is claimed.

Regression coverage includes the exact independent findings, normal CLI entry,
actual discovery, retained knowledge, public secrecy, proposal quarantine and a
committed opening where correcting Goblin 1 leaves Goblin 2 unchanged. Complete
integration and autonomous DM quality are separate acceptance questions.
