# BFDM Visual Reference Guide

**Status:** v0.1 — exemplar registry  
**Purpose:** Identify a small set of original BFDM artworks that teach the house visual language more effectively than prose alone.

The original artwork is authoritative. This guide does not reproduce the image files in the public runtime repository. Each exemplar is recorded by a stable label and SHA-256 so a private visual corpus can later recover the exact source bytes without relying on temporary filenames or chat state.

The labels below are intentionally descriptive rather than chronological. They identify what each image is useful for teaching.

---

## CORE-01 — Graphic-dark occult portrait

**SHA-256:** `e7cda4a7599e5d2e94590f85140e70a3d17cfb81553041c08c5e109e0e8b60b0`

**Teaches:**
- hard black field;
- limited palette;
- sickly teal focal anatomy;
- neon magenta/orange horizon;
- structural contour;
- silhouette-first horror;
- graphic poster read.

**Use for:** villains, occult figures, horror, faction splashes, dark chapter art.

**Do not overgeneralize:** the neon horizon is a lane, not a universal BFDM requirement.

## CORE-04 — Grotesque theatrical collision

**SHA-256:** `2af1ad6e61106a1389785b2f7d7dc468c5e649fddec3d026182450c4c1ec8008`

**Teaches:**
- cute/grotesque/theatrical horror coexistence;
- repeated eyes and faces organized into one mass;
- bright red, green, yellow, and black accents;
- internal linework controlling visual chaos;
- purposeful biological wrongness.

**Use for:** aberrations, curses, body horror, surreal monsters, nightmare art.

**Do not overgeneralize:** extra eyes and faces should be used only when the concept supports them.

## CORE-05 — Exterior / settlement design

**SHA-256:** `50ed3787c360faa0b1e3911471bba665656a291af076cdbf52c7543305b92a45`

**Teaches:**
- architecture treated like character design;
- crooked verticality;
- stacked and overhanging stories;
- strong roofline;
- dark structural line;
- bright white plaster;
- warm timber;
- cyan and orange roof accents;
- saturated green foliage and turquoise water;
- dense detail grouped into readable visual zones;
- slightly storybook perspective.

**Use for:** towns, waterfronts, settlement exteriors, establishing shots, campaign maps-as-art.

**House rule derived from this exemplar:**

> A place should have a silhouette and personality the same way a character does.

# Reference-plate groups

## Plate A — Core visual grammar

Use together when teaching general BFDM image identity:

- CORE-01
- CORE-02
- CORE-03
- CORE-04

This plate demonstrates that BFDM identity survives major changes in polish, palette, and subject because the deeper common language is concept hook, silhouette, line, color hierarchy, and selective finish.

## Plate B — Places, creatures, and objects

Use together when teaching designed-world logic:

- CORE-05
- CORE-06
- CORE-07
- CORE-08

This plate demonstrates that environments, creatures, props, and characters all receive the same expectation: **they need a readable authored shape and personality.**

## Plate C — Page design

Use together when teaching publication and handout grammar:

- CORE-09
- CORE-10
- CORE-11
- CORE-12

This plate demonstrates the BFDM preference for rules/content remaining readable while illustration, ornament, atmosphere, and page field are treated as one composition.

# How Kit should retrieve from this set

Do not attach all twelve references to every generation.

A useful starting pattern is:

- **general character:** CORE-02 + CORE-03 + CORE-08;
- **horror character:** CORE-01 + CORE-04;
- **creature:** CORE-04 + CORE-06;
- **prop:** CORE-07 plus one subject-relevant character/creature reference;
- **exterior:** CORE-05 plus one palette/line reference;
- **rulebook page:** CORE-09 + CORE-10 + CORE-11 or CORE-12;
- **Roanoke horror handout:** one page-layout exemplar plus CORE-01 or CORE-04;
- **Arcania class page:** CORE-09 + CORE-10, then retrieve subject-specific character art separately.

Reference count should normally remain small enough that the generator receives a coherent signal rather than an average of the whole corpus.

---

# Negative lesson

The exemplar set is evidence, not a bag of motifs.

Kit should not reason:

> “BFDM uses spirals, cyan, glowing eyes, masks, and parchment; add all five.”

Kit should reason:

> “Which BFDM decisions matter for this asset, and which exemplars demonstrate those decisions?”

That distinction is central to avoiding style caricature.
