# Source Containers

Canonical human-readable non-Discord source containers live here.

Path:

`sources/<project-slug>/BCS-######/`

Each BCS is one logical source document/file. See [../INGESTION_CONTRACT.md](../INGESTION_CONTRACT.md).

A source container may include:
- `source.md`
- `metadata.json`
- `comments.jsonl`
- `revisions.jsonl`
- `original/`
- `revisions/`
- `assets/`

Inclusion does not establish Brendon authorship.

Existing legacy source paths may be preserved during reconciliation rather than renamed for cosmetic consistency.
